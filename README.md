# Frank Hernandez Portfolio

Premium personal portfolio for Frank Hernandez, built with the Next.js App Router and a dark editorial visual system inspired by the supplied design reference.

## Getting Started

Install dependencies and run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

## Stack

- Next.js 16 App Router
- React 19
- TypeScript
- Tailwind CSS 4
- Sentry error monitoring

## Verification

Run these before deployment:

```bash
npm run lint
npm run typecheck
npm run build
```
